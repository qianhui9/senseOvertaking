---

### 🧭 单个 waypoint 的字段含义：

例如这行：

```
[-1000.00, 12.25, 0.00, 0.0, -0.0, 0.0]
```

表示：

* `x = -1000.00`：横向坐标
* `y = 12.25`：纵向坐标
* `z = 0.00`：高度（海拔）
* `pitch = 0.0`：车辆前倾角
* `yaw = -0.0`：航向角（转向角度）
* `roll = 0.0`：横滚角（侧倾）

这是该点的 6-自由度坐标，可以用作 `.yaml` 中的 `spawn_position` 或 `destination`。

---

### 📌 为什么每 4 个 y 值下降一次？

你看到：

```
12.25  
8.75  
5.25  
1.75  
```

说明你的地图可能是 **3-4 条纵向并排的车道**，这些 `y` 坐标代表 **不同行车道中心线的横向偏移**。

同一组 `x` 值上，多个不同的 `y` 就是不同车道的中心：

| x     | y     | 含义         |
| ----- | ----- | ---------- |
| -1000 | 12.25 | 最左车道中心线    |
| -1000 | 8.75  | 中间车道       |
| -1000 | 5.25  | 右侧车道       |
| -1000 | 1.75  | 应该是应急道或出口道 |

然后你可以看到每隔 10 米（x 值 +10）继续生成下一个点，如：

```
-1000.00
-990.00
-980.00
...
```

这就是 `carla_map.generate_waypoints(distance=10.0)` 的效果。

---

### ✅ 如何使用这些坐标？

你可以把感兴趣的坐标复制进 `.yaml` 文件，比如：

```yaml
spawn_position: [-980.00, 8.75, 0.00, 0.0, -0.0, 0.0]  # 中间车道
destination: [-700.00, 8.75, 0.00]  # 向前行驶到更小的 x
```

这些都是合法、合理的起始点和目标点，适用于你的地图。
